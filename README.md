# Expense Tracker

Личный трекер затрат с учётом денег компании на личных картах и двустороннего долга с компанией. Self-hosted, только open source: Supabase (Postgres, PostgREST, GoTrue, Storage), движок расчёта на plpgsql, фронт React.

Статус: спека v1 готова, код в работе. Спека: `.scratch/v1/spec/`, решения: `docs/adr/`.

Поставить себе на сервер (Docker, свой домен, вход через Google): `docs/deploy.md`. Локальная разработка: `docs/dev.md`.
