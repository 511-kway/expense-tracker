# 2. Журнал как источник правды, денежная логика в Postgres

Статус: принято

## Решение
- Балансы (остаток, аванс, обе стороны долга) не хранятся числом, а выводятся как сумма `delta_minor` из `ledger_entries` по `target`.
- Каждая `entries` порождает 1+ строк журнала. Вся денежная логика в функциях Postgres (plpgsql), вызывается через RPC в транзакции. Клиент только показывает и предпросматривает (предпросмотр тоже считается сервером).
- После любой правки или удаления запускается хронологический реплей счёта по реальной дате операции (тайбрейк: occurred_on, occurred_at, created_at, seq).
- Деньги целыми в минимальных единицах (тиынах), без float. Аванс и долг всегда в тенге.

## Последствия
Ретро-записи корректно меняют итог (своя рабочая трата до пополнения аванса = долг компании, после = списание с аванса). Цена: реплей при каждой правке.
