# 8. Стартовые остатки, стартовый долг и даты старта

Статус: принято (2026-11-03).

## Решение
- **Дата начала учёта** (`user_settings.accounting_start_date`): задаётся один раз при первом запуске, по умолчанию сегодня (Asia/Almaty), потом неизменна.
- **Стартовый долг**: на дату начала учёта вводятся две суммы: `company_owes_me` и `i_owe_company`, любая может быть 0. Создаются записи `adjustment` с `adjustment_target = company_owes_me | i_owe_company`, `in_analytics = false`, заголовок «Стартовый долг».
- **Дата старта счёта** (`accounts.start_date`): выбирается при создании (по умолчанию сегодня, не раньше даты начала учёта), потом неизменна.
- **Стартовый остаток счёта**: при создании вводятся «всего на счёте» и «из них компании». `create_account` создаёт на `start_date` записи `adjustment` (`plug_hidden`, заголовок «Стартовый остаток»): остаток на сумму «всего» и, если аванс > 0, аванс на сумму «компании». «Свои» = разница.
- **Граница**: запись на счёт с `occurred_on < accounts.start_date` отклоняется (`entry_before_start`). Запись без счёта (settlement без счёта, долговая корректировка) раньше `accounting_start_date` тоже отклоняется.
- Корректировка получает поле `adjustment_target`: `balance` (по умолчанию, как раньше; с `adjustment_affects_advance` двигает и аванс) или долговая сторона. Долговая корректировка не трогает остаток, не уходит в минус (проверка реплеем, ADR-0006).

## Отложено
Переразметка «свои ↔ компании» без изменения остатка. Вернёмся при реальном использовании.
