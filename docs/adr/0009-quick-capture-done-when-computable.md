# 9. Быстрый ввод: сразу запись, если движку хватает данных

Статус: принято (2026-11-03).

## Решение
Общее правило для быстрого ввода, импорта Claude Code и разбора заметок: если движок может однозначно посчитать эффект (что куда ушло, чьими деньгами, кто кому должен), запись создаётся со `status = done`. Если для расчёта чего-то не хватает, это `draft`.

Быстрый ввод в v1 только для трат (сумма, счёт, личное/работа, текст):
- work на любом счёте: done.
- personal на счёте, где аванс на дату операции = 0: done (`source = own`).
- personal на счёте с авансом > 0: draft, `source_pending = true`.

Категория для расчёта не нужна: done-трата может быть без категории (`category_id` null), в инбоксе висит отметка «без категории». Полная форма по-прежнему требует категорию.
