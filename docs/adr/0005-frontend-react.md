# 5. Фронт: React + Vite + TypeScript

Статус: принято

## Контекст
Для модели данных выбор не важен. Владельцу без разницы, критерий один: на чём проще и надёжнее писать агенту (Claude Code).

## Решение
React + Vite + TypeScript, клиент `@supabase/supabase-js`. Под React больше всего примеров, типовых паттернов и интеграций с Supabase (auth, RPC, Storage), поэтому агент реже ошибается. Node используется только как dev-сборщик, рантайма Node нет (см. ADR-0001).
