# 3. Комиссия за пополнение от компании, оплаченная мной

Статус: принято (2026-11-03). Можно пересмотреть после реального использования.

## Контекст
`company_topup` с `fee_payer = own`: банк удержал комиссию, и я её покрываю. В старой версии спеки комиссия давала `company_owes_me += fee`, но ни с какого счёта не списывалась, остаток расходился с реальностью.

## Решение
`amount_minor` = сколько компания засчитывает как аванс (landed), `fee_minor` = комиссия. Комиссия списывается с того же счёта `a`.

```
balance[a] += amount_minor - fee_minor
own_avail  = max(0, balance[a] - adv[a])       # свои деньги на счёте ДО операции, по реплею
own_part   = min(fee, own_avail)                # комиссия из своих
co_part    = fee - own_part                     # нехватка из денег компании
adv[a]    += amount_kzt_minor - co_part
# возмещение своей части: сначала гасит мой долг, остаток становится долгом компании
offset = min(own_part, i_owe_company)
i_owe_company   -= offset
company_owes_me += own_part - offset
```

Часть, оплаченная деньгами компании (`co_part`), долг не трогает: комиссию понесла компания, повторно её не компенсируем.

## Пример
Свои на H1 = 300, i_owe = 600, landed 100 000, комиссия 1 000:
balance +99 000, own_part 300, co_part 700, adv +99 300, i_owe −300, owe_me 0.

## Последствия
- Реплей ведёт по каждому счёту не только аванс, но и остаток (чтобы знать свои деньги на момент операции).
- В раскрытии долга строки возмещения привязаны к этому пополнению.
- Зачёт сторон долга только здесь, для остальных операций стороны ведутся раздельно.
