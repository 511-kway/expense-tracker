# 4. Импорт строго атомарный

Статус: принято

## Решение
Импорт файла (CSV, Excel, JSON) идёт по принципу «всё или ничего». Если хоть одна строка невалидна, весь пакет откатывается и в базе ничего не создаётся. Пользователь получает отчёт по строкам (номер строки, поле, код ошибки), исправляет файл и загружает заново.

- `import_batches.status = failed`, ошибки сохраняются в пакете для отображения. Записи и журнал не создаются.
- Вероятные дубли (по отпечатку) не считаются ошибкой: они показываются в предпросмотре, и пользователь решает, что с ними делать. Совпадение по `external_id` даёт идемпотентный пропуск.
- Невалидные строки в черновики НЕ сохраняются.

## Тест
Файл из N валидных строк и одной невалидной: в базе 0 новых записей, а отчёт указывает ровно на невалидную строку.
