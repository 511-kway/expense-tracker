# Визуальный язык

Один пользователь, русский интерфейс, тенге. Главная мысль приложения: на одной карте лежат **свои деньги** и **деньги компании**, и между мной и компанией есть **долг в обе стороны**. Дизайн делает эту двойственность видимой с первого взгляда, всё остальное тихое.

## Главный элемент

**Полоса принадлежности.** У каждого счёта и в обзоре остаток показан горизонтальной полосой из двух частей: свои (цвет «свои») и аванс (цвет «компания»). Длина частей пропорциональна суммам. Это единственный «смелый» элемент: всё, что рядом, спокойное. На экране «Расчёт с компанией» та же идея: две стороны долга как две встречные полосы от центра, итог над ними.

## Цвет

Цвет несёт смысл, а не украшает. Две смысловые краски используются только для «свои» и «компания», красный только для минуса.

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--paper` | `#F2F4F6` | `#14181F` | фон страницы (холодный, не кремовый) |
| `--surface` | `#FFFFFF` | `#1C222B` | поверхности форм и списков |
| `--ink` | `#1A2233` | `#E6EAF0` | основной текст и суммы |
| `--ink-muted` | `#5B6577` | `#98A2B3` | подписи, второстепенное |
| `--line` | `#D9DEE5` | `#2C3440` | разделители, рамки полей |
| `--own` | `#1F7A6B` | `#4FB3A1` | свои деньги, «компания должна мне» |
| `--company` | `#B87A12` | `#E0A940` | деньги компании (аванс), «я должен компании» |
| `--negative` | `#B3261E` | `#F2867E` | отрицательные суммы, ошибки |
| `--focus` | `#2F5BD3` | `#7C9BFF` | кольцо фокуса клавиатуры |

Тёмная тема через `prefers-color-scheme`. Контраст текста не ниже WCAG AA.

## Шрифт

- Одна гарнитура: **Onest** (open source, кириллица, ставится пакетом `@fontsource-variable/onest`, без внешних CDN, потому что self-hosted).
- Все суммы: `font-variant-numeric: tabular-nums`, чтобы разряды стояли ровно в колонках.
- Шкала (rem): 0.8125 / 0.9375 / 1.0625 (основной) / 1.375 / 2 / 3.
- Крупная сумма (итог, остаток в карточке) 2–3 rem, вес 600, знак валюты на ступень меньше и вес 400.
- Заголовки в обычном регистре, без капса и разрядки, без «надзаголовков» над каждым блоком.

## Раскладка

- Мобильный первым (быстрый ввод с телефона). Ширина контента не больше 720px, выравнивание по левому краю.
- Телефон: нижняя панель из 4 пунктов (Обзор, Записи, Инбокс, С компанией) и плавающая кнопка «Записать» по центру. Остальные разделы (Счета, Категории, Заметки, Импорт, Экспорт) и «Выйти» в меню «Ещё» в шапке.
- От 960px: левая колонка навигации (основные четыре раздела, линия, остальные), контент справа.

## Движение

- Одно осмысленное: полоса принадлежности плавно меняет пропорцию, когда предпросмотр или сохранение меняет суммы (200ms). Больше ничего не анимируется само.
- Ответ на действие: лист формы выезжает снизу, раскрытие стороны долга разворачивается. `prefers-reduced-motion` отключает всё.

## Текст

- Действия называют результат: «Записать трату», «Сохранить», «Удалить запись». Тост после: «Трата записана».
- Термины только из `GLOSSARY.md`: остаток, аванс, свои деньги, «компания должна мне», «я должен компании», итог с компанией. Слово «баланс» не используем.
- Ошибки говорят, что не так и как исправить: «Погасить можно не больше 30 000 ₸: столько вы сейчас должны компании».
- Пустые экраны зовут к действию: «Записей пока нет. Запишите первую трату».
- Суммы только через `formatMoney`, ввод только через `parseAmountInput` / `formatAmountInput` (`web/src/money.ts`).

## Доступность

Видимое кольцо фокуса `--focus` 2px, все действия доступны с клавиатуры, поля с подписями, цвет никогда не единственный носитель смысла (у полосы есть подписи с суммами).
