# 05: Первый запуск и стартовый долг

**What to build:** При первом входе мастер спрашивает дату начала учёта (по умолчанию сегодня) и стартовый долг двумя суммами. После этого экран «Расчёт с компанией» показывает «компания должна мне», «я должен компании» и итог с компанией. Здесь появляется движок: журнал движений, полный пересчёт в хронологическом порядке и долговые корректировки (ADR-0002, ADR-0008).

Спека: `.scratch/v1/spec.md` (формулы и числа тест-кейсов: `.scratch/v1/spec/03-engine-and-operations.md`, `06-testing.md`). Термины: `GLOSSARY.md`.
