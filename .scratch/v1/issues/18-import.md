# 18: Импорт

**What to build:** Я загружаю CSV, Excel или JSON по той же схеме, что экспорт, вижу предпросмотр с ошибками по строкам и возможными дублями и подтверждаю. Одна ошибочная строка отменяет весь файл (ADR-0004). Повторная загрузка того же файла не создаёт дублей.

Спека: `.scratch/v1/spec.md` (формулы и числа тест-кейсов: `.scratch/v1/spec/03-engine-and-operations.md`, `06-testing.md`). Термины: `GLOSSARY.md`.

**Blocked by:** 17

**Status:** ready-for-agent

- [ ] Edge Function разбирает файл в строки, суммы строкой в тиыны; `-1500.00` и `(1500.00)` оба отрицательные; больше двух знаков = ошибка строки
- [ ] Предпросмотр: валидация каждой строки, сопоставление счетов и категорий по точному названию, возможные дубли по отпечатку в окне ±3 дня
- [ ] Подтверждение одной транзакцией, при ошибке откат всей партии и пометка «неудачна», пересчёт один раз в конце, пропуск повторов по внешнему идентификатору
- [ ] Экран импорта: шаблон и правила схемы, предпросмотр, подтверждение
