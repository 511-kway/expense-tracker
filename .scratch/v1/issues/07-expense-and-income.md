# 07: Трата и поступление

**What to build:** Я записываю трату (работа или личное, категория, дата, комментарий) и поступление. Рабочая трата сначала съедает аванс, недостающее идёт в «компания должна мне». Личная со счёта с авансом спрашивает, чьими деньгами; деньги компании идут в «я должен компании». Ленту записей можно править и удалять, всё пересчитывается. Это первый полный путь записи: справочник категорий, форма, лента.

## Comments

2026-11-04, реализация:
- Миграция `supabase/migrations/20261107120000_expense_and_income.sql`: таблица `categories` (название уникально у пользователя без учёта регистра, RLS через `apply_user_rls`, с клиента только чтение), составной FK `entries (user_id, category_id)` на категории с restrict; RPC `create_category`, `rename_category`, `archive_category`, `unarchive_category`.
- Общие RPC записей по доку 05: `create_entry(p_payload)`, `update_entry(p_entry_id, p_payload)`, `delete_entry(p_entry_id)` → `{ok, entry_id, status, warnings}`; всё в одной транзакции с `engine.recompute`. Одна точка разбора по типу для проверки (`engine.check_entry` → `engine.check_<тип>`) и для движка (`engine.apply_entry` → `engine.apply_<тип>`): тикеты 09–13 добавляют ветки, payload-ридер (`engine.entry_from_payload`) уже читает все поля контракта. Правка сохраняет `id`, `created_at`, `seq`, поэтому место записи в своём дне не прыгает; смена типа очищает поля старого.
- Движок: `engine.apply_expense` (авто-сплит работы и личного деньгами компании, сплит запоминается в состоянии для возврата покупки), `engine.apply_income`. `engine.collect_warnings` получил состояние до записи: `negative_balance` при уходе остатка в минус. - Источник личной траты: вопрос только когда на счёте на момент траты есть аванс (`engine.advance_before` по журналу последнего пересчёта); иначе сервер ставит «свои». Для формы RPC `expense_source_needed`.
- Мягкий дубль по отпечатку (док 03, раздел 6), в тот же день. Выборка ленты `v_entries` с дельтами счётчиков по записи.
- Валютные суммы ждут тикета 14: запись не в тенге или на нетенговый счёт даёт `foreign_amount_not_supported`. Черновики ждут тикета 15 (`entry_status_not_supported`).
