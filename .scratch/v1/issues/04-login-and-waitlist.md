# 04: Вход и лист ожидания

**What to build:** Я вхожу через Google и попадаю внутрь. Любой другой человек после входа видит «Добавили вас в лист ожидания», его попытка записывается, сессия завершается. Без отметки «разрешён» нельзя прочитать или записать ни одной строки, даже с действующей сессией (ADR-0007).

Спека: `.scratch/v1/spec.md` (формулы и числа тест-кейсов: `.scratch/v1/spec/03-engine-and-operations.md`, `06-testing.md`). Термины: `GLOSSARY.md`.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Таблица пользователей: email, имя, разрешён (по умолчанию нет), первая и последняя попытка, число попыток
- [ ] Функция «зарегистрировать вход» добавляет или обновляет запись по email из сессии и возвращает, разрешён ли человек
- [ ] Владелец из `ADMIN_EMAIL` становится разрешённым при сбросе базы и деплое, без ручных шагов; личного email нет ни в коде, ни в тестах
- [ ] Проверка «разрешён» входит в правила доступа каждой таблицы с данными
- [ ] Экран входа через Google, экран листа ожидания, выход
- [ ] pgTAP: чужой пользователь попадает в лист ожидания, счётчик попыток растёт, неразрешённый ничего не читает и не пишет, разрешённый видит только свои строки
- [ ] В `docs/dev.md` описано, как завести Google OAuth client для localhost
