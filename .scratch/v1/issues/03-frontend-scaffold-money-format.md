# 03: Каркас фронта и формат сумм

**What to build:** Приложение на React + Vite + TypeScript открывается локально и подключается к локальному Supabase. Есть общие функции показа и ввода сумм, которыми будут пользоваться все экраны. Это подготовительный шаг: дальше каждый тикет добавляет свой экран в готовый каркас.

Спека: `.scratch/v1/spec.md` (формулы и числа тест-кейсов: `.scratch/v1/spec/03-engine-and-operations.md`, `06-testing.md`). Термины: `GLOSSARY.md`.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Фронт запускается одной командой из `docs/dev.md`, страница открывается через SSH-туннель на 127.0.0.1
- [ ] Показ суммы из тиынов: неразрывный пробел между тысячами, запятая перед копейками, копейки только если не нулевые, знак валюты (`1 500 000 ₸`, `1 500,50 ₸`, `$1 200,00`)
- [ ] Разбор ввода в тиыны без float: разделитель тысяч при наборе, копейки через запятую или точку, больше двух знаков = ошибка
- [ ] Тесты фронта на показ и разбор сумм, CI прогоняет их вместе с тестами базы
- [ ] Денежных вычислений на клиенте нет, кроме перевода тиынов в текст и обратно
